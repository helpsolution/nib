# Nib

Минималистичный редактор Markdown для macOS. ~450 строк Swift, ноль зависимостей,
нативный AppKit/SwiftUI. Никаких сайдбаров, вкладок файлов, панелей превью.

## Что внутри

- Открытие/сохранение `.md` через нативные диалоги + `⌘S`, `⌘O`, полноценный undo.
- Затухающий синтаксис в стиле iA Writer: `**`, `#`, `[]()` гаснут до серого,
  содержимое остаётся контрастным. Preview-панели нет — она не нужна.
- Центрированная колонка фиксированной ширины, line-height 1.5, автоматический
  светлый/тёмный режим (берётся из системных `NSColor`).
- Прозрачный тайтлбар, без тулбара. Счётчик слов — бледной капсулой в углу.
- `⌘+` / `⌘-` / `⌘0` — размер шрифта. `⌥⌘]` / `⌥⌘[` — ширина колонки.
  Обе настройки запоминаются.
- Подстановка «умных» кавычек и тире отключена (иначе Markdown ломается).
- `⌘F` — нативный find bar.

## Сборка

```bash
xcode-select --install        # если ещё нет Command Line Tools
cd nib
./build.sh
```

На выходе: `build/Nib.app` и `build/Nib.dmg`.

Скрипт подписывает бандл ad-hoc-подписью (`codesign --sign -`). На Apple Silicon
это обязательно — неподписанный arm64-бинарник просто не запустится. Так как
сборка локальная, карантинного атрибута нет и Gatekeeper молчит.

Если приложение всё-таки не открывается:

```bash
xattr -dr com.apple.quarantine /Applications/Nib.app
```

## Шрифт

По умолчанию берётся первый доступный из списка в `Typo.preferred`. Если поставить
бесплатные шрифты iA Writer (Duo/Quattro, лицензия SIL OFL, репозиторий
`iaolo/iA-Fonts` на GitHub) — приложение подхватит их автоматически и картинка
станет почти неотличима от оригинала. Без них используется SF Mono.

## Сделать редактором по умолчанию

Правый клик на `.md` → Get Info → Open with → Nib → Change All.

## Что можно докрутить

- Typewriter scrolling (каретка удерживается по центру).
- Focus mode: гасить все абзацы, кроме текущего — ~30 строк через
  `NSLayoutManager.temporaryAttributes`.
- Экспорт в PDF/HTML: `NSPrintOperation` для PDF, HTML потребует парсер.
- Инкрементальная подсветка вместо полного проходa: сейчас на каждое изменение
  перерисовывается весь документ с дебаунсом 90 мс. Для файлов до ~200 КБ это
  единицы миллисекунд; для мегабайтных заметок понадобится подсветка по
  диапазону абзаца.
